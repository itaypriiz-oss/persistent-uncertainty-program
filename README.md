# Persistent Uncertainty Program

Independent research program by **Itay Priiz**.

This repository organizes papers, toy models, diagrams, and notes related to the Persistent Uncertainty / Operational Admissibility framework.

## Core Principle

Global uncertainty cannot be eliminated. It can only be locally reduced through finite, irreversible, horizon-bounded processes.

This leads to a constraint-based framework in which classical spacetime, observerhood, measurement, coherence thresholds, and possible cosmological correction terms are treated as consequences of [...]

## Main Themes

- **[The Persistent Uncertainty Law](https://doi.org/10.5281/zenodo.19691111)** — A constraint law stating that global uncertainty cannot be eliminated, only locally reduced.
- [Operational admissibility](https://doi.org/10.5281/zenodo.19828875)
- Finite observers and horizon-bounded domains
- Locality from finite record access
- Coherence thresholds
- Overlap networks
- Emergent classical spacetime
- No absorbing final state
- Measurement and record formation
- Dark matter / dark energy as finite-observer correction channels
